🔐 세션 기반 암호화 엔진 설계

SCZ가 원본 데이터의 암호화·복호화를 전담하고, 세션 생명주기에 따라 키를 관리한다. — Agent는 암호화된 값만 수신하며 원본에 접근하지 않는다.
세션 생성 시 랜덤 키로 암호화하고, Agent 업무 처리가 완료(세션 종료)되면 암호화 값을 즉시 삭제한다.
